# 🌐 Growup CRM

**Growup CRM** is a complete business management solution developed by **Bluetick Creative India Pvt. Ltd.**, designed to help startups and growing businesses manage clients, leads, projects, and communication seamlessly — all in one place.

---

## 🚀 Overview

Growup CRM combines modern technology and efficient workflow automation to simplify business operations. It provides an integrated platform for managing leads, employees, payments, and client communication in real time.

This project follows a **modular MERN architecture** with a secure authentication system, real-time chat, and integrated payment features.

---

## 🧩 Tech Stack

| Layer | Technology |
|-------|-------------|
| **Frontend** | React (Vite), TypeScript, Axios, Tailwind CSS |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB (Mongoose ORM) |
| **Authentication** | JWT + Refresh Tokens |
| **Real-time Communication** | Socket.io |
| **Payment Integration** | Razorpay |
| **Deployment** | (Vercel + Render / Localhost) |

---

## ✨ Key Features

- 🔐 **User Authentication** – Secure login with JWT + Refresh token mechanism  
- 👥 **Role-based Access** – Admin, Employee & User access control  
- 💬 **Real-time Chat System** – Instant messaging powered by Socket.io  
- 📊 **Dashboard Analytics** – Overview of leads, users, and system performance  
- 💰 **Integrated Payments** – Razorpay payment gateway setup  
- 🧾 **Lead & Client Management** – Streamlined CRM flow for businesses  
- ⚙️ **Responsive Design** – Optimized for both desktop and mobile  
- 🧠 **Scalable Architecture** – Built to support long-term growth
